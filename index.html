Fight the Algorithm

How to play

Connect every town to the grid with as little cable as you can, then see whether you can beat a genetic algorithm doing the same. There's a new puzzle every day, and everyone gets the same one.

1 Start from the plain network

Each puzzle starts with the towns already joined by the shortest possible set of straight lines between them. That's the plain network, and your job is to beat it.

TownJunctionJunction that isn't helping

2 Add junctions to shorten it

Tap the board to add a junction: an extra point the cable can branch from. Drag it to fine-tune and tap it again to remove it. The network redraws itself as you go.

Three towns: one junction in the middle saves over 13%.

Four towns in a square: two junctions save almost 9%.

3 Fight the algorithm

When you're happy, press Fight the algorithm. A genetic algorithm then tackles the same puzzle while you watch.

  • It starts with random guesses, each a set of junctions.
  • Each generation, the best quarter survive and breed. Children take junctions from both parents, then mutate by gaining, losing or nudging one.
  • After generations, its best network is final.
  • The shortest network wins. You get one go at the daily puzzle, and Practice mode has unlimited puzzles.
